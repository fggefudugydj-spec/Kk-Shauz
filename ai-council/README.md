# مجلس النماذج

تطبيق ويب محلي يجمع نماذج Ollama المثبتة على جهازك في نقاش واحد، ثم يتفقون على حل المشكلة.

## المتطلبات
- Python 3.9 أو أحدث (بدون أي مكتبات إضافية)
- Ollama يعمل على جهازك: https://ollama.com
- نموذج واحد على الأقل، مثل: `ollama pull llama3.2`

## تحميل التطبيق كملف جاهز (بدون Python)
1. افتح تبويب **Actions** في المستودع واختر آخر تشغيل ناجح لـ "Build AI Council app".
2. نزّل الملف المناسب لنظامك من قسم **Artifacts**: `AICouncil-windows-latest` أو `AICouncil-macos-latest` أو `AICouncil-ubuntu-latest`.
3. فكّ الضغط وشغّل الملف `AICouncil`. يفتح المتصفح تلقائياً.

## استخدامه من الهاتف (نفس شبكة الواي فاي)
شغّل التطبيق على الكمبيوتر مع الخيار `--lan`:
```bash
AICouncil.exe --lan
```
سيظهر لك عنوان مثل `http://192.168.1.20:8765`. افتحه من متصفح الهاتف وأنت على نفس الواي فاي. هذا الخيار مخصص لشبكتك الخاصة فقط.

## التشغيل من الكود
```bash
python ai_council_app.py
```
يفتح المتصفح تلقائياً على `http://127.0.0.1:8765`. اختر النماذج، اكتب المشكلة، واضغط "ابدأ النقاش".

## الإعدادات (متغيرات بيئة اختيارية)
- `PORT`: رقم المنفذ (الافتراضي 8765).
- `OLLAMA_BASE`: عنوان Ollama (الافتراضي `http://localhost:11434`).
- `NO_BROWSER=1`: لا يفتح المتصفح تلقائياً.

## ملاحظات
- النماذج تعمل بالتناوب، لأن الذاكرة المحدودة لا تتسع لعدة نماذج معاً.
- التطبيق يكتب نصاً فقط، ولا ينفذ أوامر ولا يعدّل ملفات.
- النماذج المحلية قد تخطئ بثقة، فراجع النتيجة قبل الاعتماد عليها.
