# AI Council (مجلس النماذج المحلية)

يكتشف النماذج المثبتة في Ollama على جهازك، ويضعها في محادثة مشتركة لحل المشكلة التي تكتبها.

## المتطلبات
- Python 3.9+
- Ollama يعمل محلياً: https://ollama.com
- نموذج واحد على الأقل، مثل: `ollama pull llama3.2`

## التثبيت والتشغيل
```bash
pip install -r requirements.txt
python ai_council.py
```

## الإعدادات
في أعلى `ai_council.py`:
- `MAX_TURNS`: الحد الأقصى لعدد الرسائل في النقاش.
- `DONE_MARK`: العلامة التي يكتبها النموذج عند الاتفاق على الحل.
- `OLLAMA_BASE`: عنوان خادم Ollama.

## ملاحظات
- النماذج تعمل بالتناوب، لأن الذاكرة المحدودة لا تتسع لعدة نماذج معاً.
- التطبيق يكتب نصاً فقط، ولا ينفذ أوامر ولا يعدّل ملفات.
- النماذج المحلية قد تخطئ بثقة، فراجع النتيجة قبل الاعتماد عليها.
